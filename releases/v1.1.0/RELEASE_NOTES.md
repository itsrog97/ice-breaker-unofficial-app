**Connectoo v1.1.0**: the app is renamed to Connectoo and gets a new "Burn the Wall" call to action.

> Connectoo is an independent portfolio project: an unofficial client for the Icebreaker network, **not affiliated with, endorsed or sponsored by Icebreaker Connect, Inc.** Users sign in with their own existing Icebreaker account.

### Try it
- **Live web demo (no install, no account, fictional data):** https://itsrog97.github.io/ice-breaker-unofficial-app/
- **Android:** download [`Connectoo-v1.1.0.apk`](https://github.com/itsrog97/ice-breaker-unofficial-app/raw/main/releases/v1.1.0/Connectoo-v1.1.0.apk). It needs Android 7.0+ on an arm64 phone. Allow "install unknown apps" for your browser or Files app. The APK is signed with a test key, so Play Protect may warn you; tap *Install anyway*.
- **Design review:** [`Connectoo_Android_UIUX_Review_v1.1.0.pdf`](Connectoo_Android_UIUX_Review_v1.1.0.pdf) has 28 pages of wireframes, screens and functionality.

### What changed since v1.0.0
- New name, **Connectoo**, in the launcher, wordmark, app copy, web demo and docs.
- The profile's primary button is now **Burn the Wall**: an orange-to-red fire gradient with a flame icon. It replaces "Break the Ice".
- New Android package ID (`io.github.itsrog97.connectoo`), so it installs alongside v1.0.0. Uninstall the old "Icebreaker (Unofficial)" app.
