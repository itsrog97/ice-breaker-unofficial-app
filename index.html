Icebreaker, reimagined as a native Android app

A product-management case study: I audited the Icebreaker web product, wrote a mobile MVP spec, redesigned the experience for one-handed use, and shipped a working React Native app. Try it live in the phone frame. It runs on fictional demo data, so no account is needed.

View the case study & code Download the Android APK UI/UX review PDF

Try this in the demo

  • Tap Sign In (credentials are pre-filled)
  • Discover: search “founder”, open the Industry filter
  • Open a profile → read the reasons to connect → Break the Ice → send a message
  • Spark: tap “Find relevant people”, then “Draft an opener”
  • Chat: join the Marketing channel; open #Product Management
  • Settings (gear icon): switch on Dark Mode

What I did as the PM

  • Audited 13 routes and ~30 features; ranked them P0–P3
  • Defined the MVP vs Phase 2 scope and non-functional requirements
  • Redesigned navigation: bottom tabs, bottom-sheet filters, sticky primary action
  • Ran QA: 45 automated tests, scripted walkthroughs, failure-mode tests on 5 screen sizes

Independent project, not affiliated with, endorsed or sponsored by Icebreaker Connect, Inc. The demo is the app’s own code running in the browser; the Android build connects to the real service with a member’s own account. Implementation pair-programmed with an AI coding assistant under my product direction.
